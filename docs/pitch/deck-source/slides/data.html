[Backup · show if asked about data access] Is this feasible? Every input is free and public. OpenAQ gives us history for 21-plus CPCB stations in Mumbai. Open-Meteo gives wind and weather. Sentinel-2 gives 10-metre imagery every five days. MahaRERA lists every registered project. The one feed we can't access yet is BMC's site-sensor data, so we simulate it from real station data, and we're pursuing an RTI and vendor samples to validate it. Total data cost: zero.
