[7:30 · 25 s] For Round 2 we'll build two pilot wards end to end: K-East, Andheri East with its Metro works, and P-North, Malad. Both were flagged as dust hotspots in BMC's November drive. The forecast, Safe-Work Windows and site discovery all run on real data. Only the sensor feed is simulated, clearly labelled, with faults we inject so we can measure the Audit honestly. Our demo replays a real past spike day and shows what DustTrace would have forecast, rescheduled and flagged. We'll also build two or three DustTrace Nodes and calibrate them next to a CPCB station, so the demo includes our own live sensor.
