[4:50 · 35 s] So who decides what happens? Our Dust Response Agent. It's built the same way as the fraud-investigation agent one of us built for TigerGraph's Hacker House in Goa. Every trigger, whether a forecast, a sensor spike, a node reading, a QR report or a satellite find, becomes a case. The agent gathers evidence, weighs competing causes, and picks actions under written dust rules, each with an approval route: automatic, site manager, ward officer or Assistant Commissioner. Two rules matter most for fairness: no enforcement on a single signal, and stop-work is only ever a recommendation a human signs. And the last step is new: it checks whether the dust actually fell. If not, the case stays open.
