[Backup · show if asked how this scales beyond Mumbai or beyond dust] It scales in two directions. Across cities: Mumbai and Delhi already mandate site sensors, so they get the full product. Cities with stations but no mandate still get Predict, Prevent and Discover. NCAP covers 130 cities and has released over sixteen thousand crore, so every city already has a funded buyer. And beyond dust: the engines work for any source that stays in one place. In Mumbai, the next ones are RMC plants, wood-fired bakeries (only 209 of 593 were on clean fuel last November), open waste burning, and road dust. We went deep on one source because the brief asked us to, and we picked the biggest one.
