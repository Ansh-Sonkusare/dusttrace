[Backup · show if asked how the Audit works] Let's zoom into Audit, because this is the part nobody does today. Low-cost optical sensors fail in predictable ways, so we run six checks. Flatlines and dropouts. Readings far below the neighbours on the same wind. No dust rise during working hours on a site that's visibly active from space. Humidity bias, which is a big deal in Mumbai. Suspicious placement. And lapsed calibration. Together they give a trust score. It's a weight, not a verdict: the officer always decides.
