# Docs and assets

- `design-system.md`: colours, type, components, chart and video rules
- `product/PRD.md`: product requirements (Round 1), plus the PDF
- `pitch/`: Round 1 deck (PDF, PPTX), speaker script, and `deck-source/` (HTML slides; `deck.json` sets the order, and unlisted slides are retired)
- `prototype/dusttrace-console.html`: the clickable demo-data prototype; open it in a browser
- `video/`: 30 s teaser, the 2-min film `storyboard.md`, 1080p keyframes, screens, detail crops, phone states, and the Python render scripts in `tools/` (they reference the original sandbox paths, so adjust before running)
- `screens/`: screenshots of the MVP console
